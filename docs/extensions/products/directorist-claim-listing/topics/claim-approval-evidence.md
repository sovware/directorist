[Identity and topic index](../README.md) · [Focused issue workflow](../../../WORKFLOW.md)

## Behavior and limits

Claim submission, duplicate detection, admin approval and author transfer are separate operations. A claimed badge is presentation evidence, not proof of ownership transfer.

This is a source-derived investigation contract. Check the branches and file references below before treating it as behavior of an installed site.

## Reproduction and browser regression recipe

Use an admin-owned listing, claimant and unrelated author. Submit, repeat, reject/approve; check claim record, actual post_author, permissions and outgoing email captured locally.

Record exact inputs, expected/actual result, user role, listing/directory IDs, installed source fingerprint and environment. Use browser interactions for rendered/interactive claims; state inspection alone does not prove rendering. Restore disposable fixtures and capture errors without secrets.
