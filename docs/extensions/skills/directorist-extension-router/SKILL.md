# Directorist extension router

Read [the small routing guide](../../ROUTER.md). Run the linked `query.py route` command with the issue's exact wording and known active integration context; return candidate skills/topics. Read only the selected identity and topic pages, expanding dependencies from concrete source or configuration evidence. A-Z coverage is stored for lookup, not mandatory context.

Use [the official product index](../../INDEX.md) only when a name is unresolved. Products absent from the checked official catalog must not be assumed official because a similarly named repo exists. Candidate routing does not establish ownership.

Verify actual changed files, active plugin basename, selected branch/commit and local hashes before diagnosis. Tags, version headers and default branches are not authority. Use the issue workflow linked from the guide for full ticket/attachments, local reproduction and authorized read-only client comparison. Reuse existing support-delivery skills for generic work; this router grants no extra authorization.
